# Fall 2026 | Prosecutor Explorer

Each county folder contains its exploratory analysis and question notebook. Berkshire and Cape and Islands cover the shared Objectives. Norfolk covers the six Norfolk-specific questions.

Install the requirements in the county folder. Norfolk uses pandas, matplotlib, and IPython. Run each notebook from its own county directory.

Use the project-approved source extracts. Place these files next to the corresponding notebooks:

| County | Source files |
| --- | --- |
| Berkshire | `charges filed info.xlsx`, `disposed info.xlsx`, `bail info.xlsx` |
| Cape and Islands | `charges filed.xlsx`, `charges disposed.xlsx`, `bail_data.xlsx` |
| Norfolk | `NFK-Data-final-2017-2025 redacted.csv` |

Notebook results and figures are generated locally when the notebooks run.
