# Berkshire: all 23 shared Objectives

Open `berkshire_team_objectives_23_2017_2024.ipynb`. It follows Objectives Q1–Q23 in the shared team question document, not its final shortlist. Each question has an answerability status, result or missing-data explanation, and a visualization where supported.

Only the three local Berkshire Excel workbooks are used. There are no external population, statewide, other-county, policy, or historical crime-list inputs. Norfolk-specific questions are deferred. The earlier EDA notebook is unchanged.

Use the existing `requirements_eda.txt`. Restart Kernel and Run All from this folder or its parent. Derived outputs go to `objectives_23_outputs/`. Results are already embedded. The output folder contains a readable answer summary, the complete question-answer matrix, and a uniform visualization contract table for the team. Original-source hashes and reconciliation checks appear at the end.

Case counts use internal case ID plus defendant ID as a documented proxy for the team's docket-per-defendant unit. Outcome and source-class rollups require team agreement. Do not title the filing companion as referrals, call CWOF diversion automatically, or describe bail set/requested as money collected.
